# Ryan McSweeney Portfolio Website

This repository contains the source code for a minimalist, futuristic portfolio website for Ryan J. McSweeney. The site presents a professional résumé, highlights leadership and entrepreneurship experiences, and provides a space for showcasing academic projects.

## Features

* Responsive design with a dark, modern aesthetic.
* Separate pages for Home, About, Résumé and Projects.
* Collapsible résumé sections to convey depth without overwhelming the reader.
* Citations and footnotes referencing authoritative sources about the Theta Chi scholarship program and mentorship experiences【955042348461255†L83-L87】【301030066316132†L156-L165】.
* Placeholder cards for adding future projects.

## Getting Started

1. **Clone or download** this repository.
2. Open `index.html` in a web browser to preview the site locally.
3. To customize the content, edit the HTML files under the project root. Modify `style.css` to adjust colours, fonts or layouts.

## Deployment

This project consists of static HTML/CSS files and can be hosted on any static site hosting platform (e.g., GitHub Pages). To deploy to GitHub Pages:

1. Create a new repository on GitHub and push the contents of this folder to the repository’s root.
2. In the repository settings, enable **GitHub Pages** and choose the `main` branch as the source.
3. GitHub will publish the site at `https://<your-username>.github.io/<repository-name>/`.
